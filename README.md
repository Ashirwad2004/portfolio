# Portfolio — Ashirwad Kumar Jha

Personal portfolio site built with React, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the project at [vercel.com/new](https://vercel.com/new)
3. Vercel auto-detects Vite — no config needed

Or use the CLI:

```bash
npm i -g vercel
vercel
```

## Editing content

All copy, links, and project details live in `src/data/content.ts`.

Update your email, project URLs, FinFlow specifics, and internship descriptions there.
